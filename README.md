# Shagun Uppal — personal website

Static personal website hosted at https://shagunuppal.github.io/ through GitHub Pages.

## Local preview

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765. No build step or dependencies are required.

Pages include Home, Publications, About & news, Art, Bookshelf, and 100 Things. Shared styles and scripts provide themes, subtle animations, gallery viewers, and reading filters.

Original academic site based on Jonathan Barron’s website: https://jonbarron.info/.
